# STAT LAB datasets

- `winequality-red.csv` — красное вино, 1 599 наблюдений.
- `winequality-white.csv` — белое вино, 4 898 наблюдений.
- `aqsoldb.csv` — AqSolDB, 9 982 валидных строки анализа.
- `chembl_egfr_ic50.csv` — ChEMBL / EGFR, набор для Lab 03.
- `qm9_three_properties.csv` — QM9, набор для Lab 04.

Резервные встроенные копии всех файлов находятся в `../data-inline.js` для поддержки `file://` и отказоустойчивой загрузки.
