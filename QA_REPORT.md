# STAT LAB — QA report

## Исправление ошибки загрузки CSV

Причина ошибки `Failed to fetch`: лабораторные полагались на относительный `fetch()` к папке `data/`, а встроенная резервная копия содержала не все датасеты. При открытии через `file://` браузер блокирует такой запрос; при неудачной HTTP-загрузке также не было общего fallback.

Что изменено:
- Все пять CSV доступны в `data/`.
- `data-inline.js` пересобран и теперь содержит резервные копии всех пяти CSV.
- Лабораторные 01, 02, 03 и 04 сначала используют HTTP-загрузку там, где она доступна, а при `file://` или ошибке fetch переключаются на встроенную копию.
- Для HTTP используется URL относительно `document.baseURI`, а не неоднозначный относительный путь.
- Отмена устаревшей загрузки в лабораторных 03/04 сохранена.
- README обновлён: прямое открытие `index.html` и запуск через локальный сервер поддерживаются.
