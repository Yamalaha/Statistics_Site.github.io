# STAT LAB — исправленная сборка

## Что исправлено
- Все пять актуальных CSV размещены в `data/`: AqSolDB, ChEMBL/EGFR, QM9, Wine Red и Wine White.
- `data-inline.js` содержит резервные копии всех пяти CSV; все лабораторные могут открываться напрямую через `file://` без сетевого fetch.
- При запуске по HTTP загрузчики используют URL относительно `document.baseURI`, а при ошибке загрузки переходят на встроенную копию.
- Исправлена обработка загрузки данных во всех четырёх лабораторных: 01 (Wine), 02 (AqSolDB), 03 (ChEMBL), 04 (QM9).
- Сохранены проверки схемы и числовых полей; фиктивные данные не используются.

## Запуск через локальный сервер (рекомендуется)
```bash
python -m http.server 8000
```
Откройте `http://localhost:8000`.

## Открытие без сервера
Можно открыть `index.html` напрямую. Встроенные резервные копии CSV обеспечивают работу всех четырёх лабораторных.

## Структура данных
Все исходные CSV находятся в `data/`. `data-inline.js` — резервная копия для офлайн-режима; после изменения CSV пересоберите этот файл, чтобы копии оставались синхронизированы.
